What's New

  • SandClean now checks for updates automatically and notifies you when a new version is available
  • New AI Analysis feature — get smart recommendations on whether files are safe to delete, powered by Apple Foundation Models or Claude CLI
  • New Unused Files scanner and redesigned Disk Visualizer as Space Lens for a clearer picture of what's taking space
  • Duplicate Photos scanner now shows image previews in a grouped card layout for easier review
  • You can now update individual Homebrew packages directly from the Deep Clean view, with per-formula notifications
  • Added Select All per group in Xcode Cleaner, full device names in iOS Device Support, and ⌘R shortcut across all scanner views
  • Menu Bar widget redesigned with a storage ring gauge and category breakdown
  • Fixed an issue where cleaning notifications would sometimes appear twice; improved iCloud scan to run in the background without causing pauses
  • App is now available in English, Indonesian, and Spanish
